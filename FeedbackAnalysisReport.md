### [high] · Export · 2026-07-17
**Feedback:** Stata workbench doesn't work completely

**File:** `src/components/calculate/workbench/exportScript.js` (`buildStata`, lines 79–131)

**Suggestion:** Root cause confirmed: the generated Mata code has two structural defects making it non-runnable. (1) Standalone computation blocks (derivative, integral, optimize, solveZero) are emitted after `}` closes the function body but still inside the same `mata:` … `end` block — in Mata, only function definitions may appear at top-level inside `mata:` blocks; executable statements outside a function require a separate `mata:` entry. (2) Print expressions use bare tuple syntax `("label", value)` which is not valid Mata — should be `printf("label: %f\n", value)`. Fix: wrap each standalone computation block in its own `mata:` / `end` pair, and replace all print tuples with `printf()` calls. The R and Python paths in the same file appear structurally correct.

**Invariants:** Pure export-layer change, no React, no math engine changes.
